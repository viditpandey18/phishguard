            URL forensics
            Look-alike and homoglyph domains (paypa1.com, Cyrillic аpple), brand names buried in subdomains, shorteners, raw-IP hosts, abused TLDs, free-hosting phishing kits.
            
          
            Language signals
            Urgency, threats, "digital arrest", KYC/PAN lures, KBC lotteries, job and investment scams, AnyDesk requests. Recognises OTP requests but not "never share your OTP" advice.
            
          
            Email authentication
            SPF / DKIM / DMARC results, Reply-To and Return-Path mismatches, display-name spoofing, brands sending from Gmail, dangerous attachments like invoice.pdf.exe.
            
          
            Explainable scoring
            Every signal adds weighted log-odds; the total is calibrated into a probability. Each red flag shows its exact contribution, so there's no black box.

            Privacy & security by design
            
            
              
              
            • Messages are analysed in memory and never stored. Feedback keeps detection signals only.
              • 
              
            • Links are never visited. External lookups are off by default.
              • 
              
            • PII (phones, UPI IDs, cards, Aadhaar, PAN) is redacted from logs.
              • 
              
            • Rate limiting, size limits, strict CSP, and API-key auth.
              •
